# GL渲染模式下设置透明物体

## 实现原理

在 GL 渲染模式下，物体的透明度通过 `macros.py` 中 `COLOR` 字典的 **alpha 通道**（第4个值）控制。

### 颜色格式
```python
COLOR[MATERIAL] = (R, G, B, A)  # RGBA格式
# R, G, B: 0.0-1.0，红绿蓝通道
# A: 0.0-1.0，alpha通道（透明度）
#   - 0.0: 完全透明
#   - 0.3: 半透明（推荐用于玻璃）
#   - 0.5: 中等透明
#   - 1.0: 完全不透明
```

## 设置杯子透明

### 方法1：修改 BOTTLE 材质（推荐）
如果 agent 使用 `BOTTLE` 材质（如 `glass.obj`），直接修改 `BOTTLE` 的颜色：

```python
# fluidlab/configs/macros.py
COLOR = {
    # ...
    BOTTLE: (0.70, 0.95, 0.96, 0.3),  # alpha=0.3，半透明玻璃效果
    # ...
}
```

### 方法2：使用自定义材质
如果不想影响其他使用 `BOTTLE` 的地方，可以：
1. 在 `macros.py` 中定义新材质（如 `GLASS_CUP`）
2. 在 agent 配置中使用新材质

```python
# fluidlab/configs/macros.py
GLASS_CUP = 58  # 新材质ID
COLOR = {
    # ...
    GLASS_CUP: (0.70, 0.95, 0.96, 0.3),  # 透明玻璃杯
    # ...
}
```

```yaml
# fluidlab/envs/configs/agent_tablematerials.yaml
mesh:
  material: GLASS_CUP  # 使用新材质
```

## 透明度参考值

| 材质类型 | Alpha 值 | 效果 |
|---------|---------|------|
| 完全透明 | 0.0 | 不可见 |
| 高度透明 | 0.1-0.2 | 几乎透明，隐约可见 |
| 半透明玻璃 | 0.3-0.4 | **推荐用于玻璃杯** |
| 中等透明 | 0.5-0.6 | 可见但透明 |
| 低透明度 | 0.7-0.9 | 轻微透明 |
| 不透明 | 1.0 | 完全不透明 |

## 当前设置

- **BOTTLE** (glass): `(0.70, 0.95, 0.96, 0.3)` - 半透明玻璃效果
- **CUP**: `(0.9, 0.9, 0.9, 1.0)` - 不透明（纸杯）

## 注意事项

1. **透明度渲染顺序**：GL 渲染器需要正确的渲染顺序才能正确显示透明效果
2. **性能影响**：透明物体会增加渲染负担，特别是多个透明物体重叠时
3. **视觉效果**：alpha 值过小（<0.2）可能导致物体几乎不可见
4. **材质一致性**：如果同一个材质用于多个物体，修改会影响所有使用该材质的物体

## 测试建议

1. **初始设置**：使用 `alpha=0.3`（半透明玻璃效果）
2. **观察效果**：
   - 如果太透明（看不清）→ 增加到 `0.4-0.5`
   - 如果不够透明（看不清内部）→ 降低到 `0.2-0.25`
3. **根据场景调整**：
   - 需要看清内部流体 → `0.2-0.3`
   - 需要看清杯子轮廓 → `0.4-0.6`

# 纸杯子摩擦系数设置建议

## 现实中的纸杯摩擦特性

### 1. 纸杯表面材料
- **内壁涂层**：通常涂有聚乙烯（PE）或聚乳酸（PLA）等材料
- **表面特性**：
  - 比玻璃更粗糙
  - 但涂层材料本身摩擦系数较低
  - 通常比光滑的玻璃杯摩擦系数稍高

### 2. 摩擦系数范围
根据材料科学数据：
- **纸杯内壁（PE涂层）**：约 **0.1 - 0.3**
- **纸杯内壁（PLA涂层）**：约 **0.15 - 0.25**
- **无涂层纸杯**：约 **0.3 - 0.5**（更粗糙）

### 3. 与液体的相互作用
- **低粘度液体（如水）**：摩擦系数接近材料本身的摩擦系数
- **高粘度液体（如蜂蜜）**：虽然摩擦系数不变，但粘性阻力更大，看起来"更粘"

## 当前代码设置

```python
FRICTION = {
    CUP     : 0.5,   # 当前设置（可能偏高）
    BOTTLE  : 0.1,   # 玻璃杯（光滑表面）
    TABLE   : 2.0,   # 桌子（高摩擦）
}
```

## 建议设置

### 方案1：标准纸杯（推荐）
```python
CUP: 0.2  # 适用于大多数纸杯（有PE/PLA涂层）
```
- **理由**：
  - 在0.1-0.3的合理范围内
  - 比玻璃杯（0.1）稍高，符合纸杯更粗糙的特性
  - 不会过高，避免过度"粘"住流体

### 方案2：粗糙纸杯
```python
CUP: 0.3  # 适用于无涂层或粗糙表面的纸杯
```
- **理由**：
  - 适用于表面更粗糙的纸杯
  - 如果观察到流体在纸杯中"粘"得太紧，可以降低

### 方案3：光滑纸杯（特殊涂层）
```python
CUP: 0.15  # 适用于有特殊光滑涂层的纸杯
```
- **理由**：
  - 接近玻璃杯的摩擦系数
  - 适用于有特殊处理的纸杯

## 对比参考

| 材料 | 摩擦系数 | 说明 |
|------|---------|------|
| 玻璃（BOTTLE） | 0.1 | 光滑表面 |
| 纸杯（PE涂层） | 0.2 | 推荐值 |
| 纸杯（粗糙） | 0.3 | 无涂层或粗糙表面 |
| 桌子（TABLE） | 2.0 | 高摩擦，防止滑动 |

## 实际测试建议

1. **初始设置**：使用 `0.2`
2. **观察行为**：
   - 如果流体在纸杯中滑动太快 → 增加到 `0.3`
   - 如果流体"粘"得太紧 → 降低到 `0.15`
3. **根据材料调整**：
   - 有光滑涂层的纸杯 → `0.15 - 0.2`
   - 普通纸杯 → `0.2 - 0.3`
   - 粗糙纸杯 → `0.3 - 0.4`

## 结论

**推荐设置：`CUP: 0.2`**

这个值：
- 在物理上合理（0.1-0.3范围内）
- 比玻璃杯稍高，符合纸杯更粗糙的特性
- 不会过度影响流体的运动
- 可以根据实际观察进行微调

# Herschel-Bulkley 材料说明

## 9种常见材料参数

环境 `TableMaterialsEnv` 中使用的9种基于Herschel-Bulkley模型的材料：

### 1. WATER_NEWTON (牛顿流体)
- **类型**: 牛顿流体
- **参数**: n=1.0, τ_y=0.0, K=1.0
- **颜色**: 蓝色 (0.2, 0.5, 0.9)
- **密度**: 1.0
- **特性**: 恒定粘度，无剪切依赖性

### 2. HONEY (蜂蜜)
- **类型**: 剪切变稀 (Pseudoplastic)
- **参数**: n=0.5, τ_y=0.0, K=5000.0
- **颜色**: 金黄色 (0.95, 0.75, 0.2)
- **密度**: 1.4
- **特性**: 强剪切变稀，高粘度，无屈服应力

### 3. KETCHUP (番茄酱)
- **类型**: 剪切变稀 + 屈服应力
- **参数**: n=0.3, τ_y=20.0, K=200.0
- **颜色**: 红色 (0.9, 0.1, 0.1)
- **密度**: 1.1
- **特性**: 强剪切变稀，有屈服应力（需要挤压才能流动）

### 4. TOOTHPASTE (牙膏)
- **类型**: 剪切变稀 + 屈服应力
- **参数**: n=0.4, τ_y=25.0, K=300.0
- **颜色**: 白色 (0.95, 0.95, 1.0)
- **密度**: 1.2
- **特性**: 剪切变稀，高屈服应力

### 5. BLOOD (血液)
- **类型**: 剪切变稀
- **参数**: n=0.7, τ_y=5.0, K=50.0
- **颜色**: 深红色 (0.6, 0.1, 0.1)
- **密度**: 1.05
- **特性**: 轻微剪切变稀，轻微屈服应力

### 6. PAINT (油漆)
- **类型**: 剪切变稀 + 屈服应力
- **参数**: n=0.6, τ_y=10.0, K=150.0
- **颜色**: 黄色 (0.9, 0.7, 0.1)
- **密度**: 1.3
- **特性**: 剪切变稀，有屈服应力

### 7. CORNSTARCH (玉米淀粉浆)
- **类型**: 剪切增稠 (Dilatant)
- **参数**: n=1.5, τ_y=0.0, K=100.0
- **颜色**: 浅黄色 (1.0, 1.0, 0.9)
- **密度**: 1.1
- **特性**: 剪切增稠（快速搅拌时变稠）

### 8. SILLY_PUTTY (橡皮泥)
- **类型**: 剪切增稠
- **参数**: n=1.3, τ_y=0.0, K=2000.0
- **颜色**: 紫色 (0.8, 0.6, 0.9)
- **密度**: 1.2
- **特性**: 剪切增稠，高粘度

### 9. YOGURT (酸奶)
- **类型**: 剪切变稀 + 屈服应力
- **参数**: n=0.6, τ_y=12.0, K=400.0
- **颜色**: 乳白色 (1.0, 0.98, 0.9)
- **密度**: 1.05
- **特性**: 剪切变稀，有屈服应力

## 材料分类

### 按流动指数 (n) 分类：
- **n = 1.0**: 牛顿流体 (WATER_NEWTON)
- **n < 1.0**: 剪切变稀 (HONEY, KETCHUP, TOOTHPASTE, BLOOD, PAINT, YOGURT)
- **n > 1.0**: 剪切增稠 (CORNSTARCH, SILLY_PUTTY)

### 按屈服应力 (τ_y) 分类：
- **τ_y = 0**: 无屈服应力 (WATER_NEWTON, HONEY, CORNSTARCH, SILLY_PUTTY)
- **τ_y > 0**: 有屈服应力 (KETCHUP, TOOTHPASTE, BLOOD, PAINT, YOGURT)

## 自动启用 H-B 模型

系统会自动检测并启用Herschel-Bulkley模型，条件是：
- `yield_stress > 1e-6` 或
- `abs(flow_index - 1.0) > 1e-6`

因此，除了 `WATER_NEWTON`（牛顿流体）外，其他8种材料都会自动使用H-B模型。

## 参数说明

- **CONSISTENCY (K)**: 稠度系数，主要粘度参数
- **YIELD_STRESS (τ_y)**: 屈服应力，材料开始流动所需的应力
- **FLOW_INDEX (n)**: 流动指数
  - n = 1: 牛顿流体
  - n < 1: 剪切变稀
  - n > 1: 剪切增稠
- **MU**: 从CONSISTENCY派生，用于mu_max计算和向后兼容
- **RHO**: 密度
- **LAMDA**: 体积模量

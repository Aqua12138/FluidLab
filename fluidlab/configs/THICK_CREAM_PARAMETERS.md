# THICK_CREAM 非牛顿粘稠材料参数说明

## 材料概述

`THICK_CREAM` 是一个基于 Herschel–Bulkley 模型的非牛顿粘稠材料，专门设计用于模拟粘稠的奶泡或奶油等流体。该材料具有**剪切变稀**（shear-thinning）特性和**屈服应力**（yield stress），能够更好地模拟真实世界中粘稠流体的行为。

## 参数详解

### 1. MU (μ) = 400.0
**物理意义：基础剪切模量/粘度**

- **作用**：这是材料的基准粘度值，用于计算最大粘度限制（mu_max）
- **单位**：无量纲（在MPM模拟中的相对单位）
- **影响**：
  - 当材料静止或剪切速率极低时，有效粘度会接近 mu_max = mu × 1000 = 400,000
  - 这确保了材料在静止时保持粘稠，不会过度流动
  - 防止CFL条件导致的时间步长过小问题

### 2. YIELD_STRESS (τ_y) = 15.0
**物理意义：屈服应力**

- **作用**：材料开始流动所需的最小剪切应力
- **单位**：无量纲（在MPM模拟中的相对单位）
- **物理含义**：
  - 当施加的剪切应力 < 15.0 时，材料表现为**类固体**，几乎不流动
  - 当剪切应力 ≥ 15.0 时，材料开始流动
  - 这模拟了真实奶泡的特性：静止时能保持形状，但受到足够力时开始流动

**实际效果**：
- 材料在静止时能"站立"，不会立即塌陷
- 倾倒时，需要一定的力才能让材料流动
- 适合模拟需要保持形状的粘稠流体（如拉花艺术中的奶泡）

### 3. CONSISTENCY (K) = 350.0
**物理意义：稠度系数**

- **作用**：控制非牛顿流体的基础粘度水平
- **单位**：无量纲（在MPM模拟中的相对单位）
- **在Herschel–Bulkley模型中的作用**：
  - 有效粘度公式：`μ_eff = τ_y × (1-exp(-m×γ̇))/γ̇ + K × γ̇^(n-1)`
  - K 值越大，材料在流动时的基础粘度越高
  - 与流动指数 n 共同决定材料的粘度随剪切速率的变化

**实际效果**：
- K = 350.0 提供了中等偏高的基础粘度
- 即使在高剪切速率下，材料仍保持一定的粘稠感
- 与 n = 0.65 配合，实现剪切变稀但不过度稀薄的效果

### 4. FLOW_INDEX (n) = 0.65
**物理意义：流动指数**

- **作用**：决定材料的流变特性类型
- **取值范围**：通常 0.1 - 2.0
- **物理含义**：
  - **n = 1.0**：牛顿流体（粘度恒定，如水）
  - **n < 1.0**：剪切变稀（pseudoplastic），粘度随剪切速率增加而降低
  - **n > 1.0**：剪切增稠（dilatant），粘度随剪切速率增加而增加

**n = 0.65 的效果**：
- **剪切变稀**：当材料被搅拌、倾倒或受到剪切时，粘度会降低
- **实际表现**：
  - 静止时：高粘度，保持形状
  - 缓慢流动时：中等粘度
  - 快速流动/搅拌时：粘度降低，流动更顺畅
- **模拟场景**：
  - 拉花时，奶泡在注入时（高剪切）变稀，便于形成图案
  - 静止时（低剪切）恢复粘稠，保持图案形状

### 5. RHO (ρ) = 0.8
**物理意义：密度**

- **作用**：材料的质量密度
- **单位**：相对密度（水 = 1.0）
- **物理含义**：
  - RHO = 0.8 表示材料比水轻 20%
  - 这模拟了奶泡的特性：由于含有气泡，密度低于纯液体
- **影响**：
  - 影响重力作用：较轻的材料受重力影响较小
  - 影响惯性：质量越小，惯性越小，更容易被外力改变运动状态
  - 影响浮力：在咖啡（RHO = 1.0）上方时，会自然上浮

### 6. LAMDA (λ) = 277.78
**物理意义：体积模量参数（拉梅第一参数）**

- **作用**：控制材料的可压缩性
- **单位**：无量纲（在MPM模拟中的相对单位）
- **物理含义**：
  - 控制材料抵抗体积压缩的能力
  - 值越大，材料越难压缩
  - 在Herschel–Bulkley模型中，**此参数保持不变**，只影响体积应力（压力项）

## Herschel–Bulkley 模型公式

该材料使用以下本构模型：

```
τ = τ_y + K × (γ̇)^n
```

其中：
- **τ**：剪切应力
- **τ_y = 15.0**：屈服应力
- **K = 350.0**：稠度系数
- **γ̇**：剪切速率
- **n = 0.65**：流动指数

**有效粘度**（使用Papanastasiou正则化）：

```
μ_eff(γ̇) = min(
    τ_y × (1 - exp(-100×γ̇)) / γ̇ + K × γ̇^(n-1),
    mu_max = 400,000
)
```

## 参数组合效果

这些参数的组合产生了以下特性：

1. **静止时**：
   - 高有效粘度（接近 mu_max）
   - 屈服应力阻止流动
   - 材料能保持形状

2. **缓慢流动时**：
   - 中等有效粘度
   - 屈服应力被克服
   - 材料开始流动但保持粘稠

3. **快速流动/搅拌时**：
   - 有效粘度降低（剪切变稀）
   - 流动更顺畅
   - 但仍保持一定粘稠感

## 在拉花艺术中的应用

在 `exp_latteart.yaml` 中使用 `THICK_CREAM` 替代原来的 `MILK` 材料，会产生以下效果：

1. **更好的形状保持**：奶泡注入后能更好地保持图案形状
2. **更真实的流动**：倾倒时表现出粘稠流体的特性
3. **剪切变稀效果**：在注入过程中（高剪切）变稀，便于形成图案；静止后（低剪切）恢复粘稠，保持图案

## 参数调整建议

如果需要调整材料特性，可以修改以下参数：

- **更粘稠**：增加 `YIELD_STRESS`（如 20-30）或 `CONSISTENCY`（如 400-500）
- **更稀薄**：减少 `YIELD_STRESS`（如 5-10）或 `CONSISTENCY`（如 200-300）
- **更强的剪切变稀**：减少 `FLOW_INDEX`（如 0.5-0.6）
- **更接近牛顿流体**：增加 `FLOW_INDEX`（如 0.8-0.9）
- **更轻**：减少 `RHO`（如 0.7-0.75）
- **更重**：增加 `RHO`（如 0.85-0.9）
